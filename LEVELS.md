# Fairy Maze: level format

Every level is a text grid. Each character is one square:

| char | meaning |
|------|---------|
| `#`  | wall (bumps the fairy back gently) |
| `.`  | open path (a space works too) |
| `S`  | start (exactly one) |
| `E`  | the black hole / end (exactly one) |
| `*`  | a star to collect (optional, any number) |

Rows may be different lengths; short rows are padded with walls. If the outer edge isn't all walls, a wall border is added automatically. The maximum size is 40x40, and 7x7 to 17x13 plays best on phones. The game turns a wide maze sideways on a portrait phone so it stays big.

Example:
```
#########
#S.*....#
###.#*#.#
#.*.#..*#
#.###.#.#
#....*.E#
#########
```

## Adding a custom level (for example from a photo of a paper maze)
1. Turn the drawing into a grid. Each drawn corridor becomes `.` cells, each pencil line or block becomes `#`, then mark `S`, `E`, and a few `*`.
   Tip: think of the paper as a checkerboard where corridors and walls each take one square.
2. Save it as a text file, e.g. `rainbow.txt`.
3. Run:
   ```
   python3 add_level.py rainbow.txt --name "Rainbow Maze"
   ```
   This checks that there's one S and one E, that the black hole can be reached, and that all stars can be reached. It then saves the level to `levels/custom/rainbow_maze.txt` and regenerates `levels/custom.js`.
   Use `--check` to validate without saving, and `--order N` to set the position in Our Mazes (lower comes first; files without an order go last).
4. Re-upload or redeploy the folder. The level shows up under **Our Mazes** on the start screen. Tapping a tile plays that maze, and **Next** continues through the following custom mazes in order.

To remove a level, delete its file in `levels/custom/` and run `python3 add_level.py --rebuild`.

Built-in levels (the 5-level main game) live in `levels/builtin.js` and are generated by `gen_builtin.py`.

## Big mazes and areas (Giant Adventures)
- Grids can be up to 80x80. When a maze would shrink below a comfortable tile size (under about 26 px), the game switches to **camera mode**: tiles stay 34 to 48 px and the view smoothly follows Floaty. Small mazes still fit the whole screen as before.
- A level can be split into themed **areas** with extra header lines (rows and columns are 0-based and inclusive):
  ```
  ; area: Sunflower Meadow | 0,0,14,22 | #e0a82e | 🌻
  ```
  The fields are name, rectangle `r0,c0,r1,c1`, wall color, and emoji. Walls inside an area use its color. When Floaty enters an area, the camera glides over to frame it (or follows her inside it if the area is bigger than the screen), and a small name banner fades in at the top.
- `gen_giant.py` regenerates the Giant Adventures set (fixed seeds): `python3 gen_giant.py`.
